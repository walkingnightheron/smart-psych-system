# 智慧心理健康评估系统

面向学校心理健康教育中心的问卷评估系统（教学实训项目，三周 72 学时）。

- 管理端（PC）：问卷配置与版本、活动管理、进度与统计 —— Vue 3
- 参与端（H5）：活动查询、问卷填写、个人报告 —— UniApp H5
- 后端：身份权限、事务提交、计分报告、Redis 缓存、RabbitMQ 异步 —— Spring Boot

## 目录规划

```text
backend/   Spring Boot 后端
pc-web/    Vue 3 管理端
h5-app/    UniApp H5 参与端
docs/      设计资料与交付文档
```

## 功能需求（REQ）

REQ01 身份与个人信息 · REQ02 问卷配置 · REQ03 问卷发布与版本 · REQ04 活动管理 · REQ05 活动查询与填写 · REQ06 提交与个人记录 · REQ07 计分与报告 · REQ08 结果统计 · REQ09 热点缓存 · REQ10 异步报告

> 数据、账号与问卷均为教学模拟内容，结果仅用于软件功能验证，不作医学诊断。
